\chapter*{Code source}
\addcontentsline{toc}{chapter}{Code source}
Cette annexe présente le code source de l'application DiatonyDAW. Les fichiers sont organisés en quatre parties : les fichiers d'en-tête (headers), les fichiers d'implémentation (sources), les fichiers de configuration et de compilation, et une sélection de tests unitaires.\\

Les \textbf{instructions d'installation}, le \textbf{tutoriel d'utilisation} ainsi que d'autres informations techniques sont disponibles via le fichier README.md de mon dépôt GitHub sur la branche main : \url{https://github.com/cedricniyi/DiatonyDawApplication}
